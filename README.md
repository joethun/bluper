## Features Added
- Freeze Frame
- Transitions
- Fade in and out
- Adjust
- Effects
- Minor UI changes
- Numerous bug fixes

## Why?

- **Privacy**: Your videos stay on your device
- **Free features**: Most basic CapCut features are now paywalled 
- **Simple**: People want editors that are easy to use - CapCut proved that
